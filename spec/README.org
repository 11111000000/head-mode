This repository contains the formal specification for head-mode, an Emacs minor mode that renders a contextual breadcrumb header for buffers. The spec is split across multiple focused Org files. Each topic is defined once and referenced elsewhere to avoid duplication.

How to read this spec
- Start with Goals and Scope for a high-level overview.
- Continue with UX and Requirements for behavior and constraints.
- Architecture explains the moving parts and how they fit together.
- Consult Data Model for the canonical definitions (Section object, Provider API, State).
- Providers, Layout and Rendering, Icons and Styles, Configuration and Profiles, and Interactions and Menus detail key subsystems.
- Performance and Reliability, Compatibility and Degradation, Testing and CI cover cross-cutting qualities.
- Language Mappings contains initial treesit mappings.
- Roadmap and Risks outlines release stages and mitigations.
- Glossary defines terms used across the spec.

Conventions
- Cross-references use Org links to canonical sections (e.g., [[file:05-data-model.org#section-object][Section object]]).
- Configuration variable and function names are presented as symbols for clarity; actual implementation details are out of scope for this document.
- This spec targets Emacs 29+ and assumes availability of treesit; see [[file:11-compatibility-and-degradation.org][Compatibility and Degradation]] for fallbacks.
